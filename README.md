Superstore-End-to-End-Data-Analysis

End-to-End Sales Data Analysis using Python, MySQL, Excel & Power BI | Data Cleaning, SQL Analysis, Interactive Dashboards and Business Insights.

📌 Project Overview

This project focuses on analyzing the Sample Superstore dataset to identify sales trends, profitability patterns, product performance, and regional business insights.

The project follows an end-to-end data analytics workflow using Python, MySQL, Excel, and Power BI.

🎯 Project Objectives

- Clean and prepare raw sales data.
- Perform data analysis using Python and Pandas.
- Write SQL queries to analyze business data.
- Create an Excel dashboard for sales reporting.
- Build an interactive Power BI dashboard.
- Identify useful business insights from the data.

🛠️ Tools & Technologies

- Python: Data Cleaning and Analysis
- Pandas: Data Manipulation
- MySQL: SQL Queries and Data Analysis
- Microsoft Excel: Data Analysis and Dashboard
- Power BI: Interactive Dashboard and Data Visualization

🔄 Project Workflow

1. Data Cleaning using Python

- Loaded the Sample Superstore dataset.
- Explored the dataset using Pandas.
- Checked data quality and prepared the data for analysis.

2. SQL Analysis using MySQL

- Imported the dataset into MySQL.
- Performed sales and profit analysis.
- Analyzed category, region, segment, and product performance.

3. Excel Dashboard

- Performed data analysis using Excel.
- Created charts and an interactive dashboard.
- Presented important sales and profit metrics.

4. Power BI Dashboard

- Created KPI cards and interactive visualizations.
- Analyzed monthly sales trends.
- Compared category-wise and region-wise performance.
- Analyzed segment contribution and top 10 products.
- Used slicers to make the dashboard interactive.
